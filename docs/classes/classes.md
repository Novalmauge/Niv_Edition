# Approved Classes

The following custom classes are balanced and approved for this campaign. 

| Class | Description | Primary Ability |
| :--- | :--- | :--- |
| **Warlord** | A martial support class that directs ally positioning. | Strength, Charisma |
| **Blood Hunter** | A martial class sacrificing vitality for esoteric damage. | Dexterity, Intelligence |

Review the [Sidekick & Cohort Classes](sidekick_class.md) if you are managing a retainer.
